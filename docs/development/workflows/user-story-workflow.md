# User Story Workflow

GitHub Issues workflow for feature development.

## Process

1. **Create**: Use issue templates, assign domain labels
2. **Prioritize**: High (MVP), Medium, Low, Post-MVP
3. **Implement**: Feature branch, TDD, acceptance criteria
4. **Review**: PR review against acceptance criteria
5. **Close**: Merge and close issue

## User Story Format

```
As a [user type], I want [goal] so that [benefit].
```

**Example**: "As a player, I want to create custom characters so that I can tailor my gameplay experience."

## Domains

- World Configuration
- Character System  
- Narrative Engine
- Journal System
- State Management
