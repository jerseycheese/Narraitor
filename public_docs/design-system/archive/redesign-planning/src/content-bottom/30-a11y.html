Accessibility (WCAG 2.1 AA)

All components and patterns must meet WCAG 2.1 Level AA standards minimum.

Color Contrast Requirements

STANDARD TEXT (< 18px)
4.5:1 minimum
  • Light mode: text-primary on canvas = 18.27:1 ✓
  • Dark mode: text-primary on dark-canvas = 19.06:1 ✓
LARGE TEXT (≥ 18px or bold ≥ 14px)
3:1 minimum
  • Narrative text (18px) meets enhanced 4.5:1 standard ✓
  • System labels (14px mono, muted) on canvas = 4.68:1 ✓
UI COMPONENTS & GRAPHICS
3:1 minimum
  • Primary accent indicators on canvas = 11.05:1 ✓
  • Button text (white on accent) = 11.42:1 ✓

Focus Indicators

All interactive elements must have visible focus indicators with 3:1 contrast.

outline: 2px solid var(--color-accent); outline-offset: 2px;

FOCUS STANDARDS

  • Minimum 2px outline or border
  • 2px offset for better visibility
  • Never remove focus styles (no outline: none)
  • Focus order follows logical reading flow
  • Skip links for keyboard navigation

Touch Target Sizes

Minimum touch target 44px × 44px
Primary buttons 48px height minimum
Icon buttons 44px × 44px (include padding)
Spacing between targets 8px minimum

Keyboard Navigation

REQUIRED SUPPORT
  • Tab / Shift+Tab navigation
  • Enter / Space activation
  • Escape to close modals
  • Arrow keys for lists/menus
  • Home / End navigation
FOCUS MANAGEMENT
  • Trap focus in modals
  • Return focus on close
  • Skip navigation links
  • Logical tab order
  • No keyboard traps

Screen Reader Support

SEMANTIC HTML
  • Use semantic elements (<nav>, <main>, <article>, <section>)
  • Proper heading hierarchy (h1 → h6, no skipping)
  • Lists for related items (<ul>, <ol>)
  • Buttons for actions, links for navigation
ARIA PATTERNS
aria-label for icon-only buttons
aria-expanded for collapsible sections
aria-live="polite" for streaming text updates
aria-describedby for form field hints
role="status" for loading indicators
aria-hidden="true" for decorative elements
SPECIAL CONSIDERATIONS FOR AI STREAMING
  • Use aria-live="polite" on narrative container
  • Don't announce every token (causes speech overload)
  • Provide "Stop Reading" control for screen readers
  • Include skip link to bypass generated content

Motion & Animation

RESPECT USER PREFERENCES
Always respect prefers-reduced-motion media query. Disable or reduce animations when requested. 
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
