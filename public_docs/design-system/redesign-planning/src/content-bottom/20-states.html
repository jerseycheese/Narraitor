IMPLEMENTATION NOTES

  • All state transitions should use transition-all duration-150
  • Active state includes subtle scale: transform: scale(0.98)
  • Loading states reduce opacity to 0.7 and show spinner
  • Error/success states must meet 4.5:1 contrast ratio
  • Never rely on color alone—use icons or text labels
