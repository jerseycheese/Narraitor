Motion & Animation

Subtle, purposeful motion that enhances usability without distraction.

Duration Scale

75ms
Micro-interactions (hover, focus)
150ms
Default transitions
300ms
Panel slides, dropdowns
500ms
Page transitions, modals

Easing Functions

ease-out
Elements entering the screen
cubic-bezier(0, 0, 0.2, 1)
ease-in
Elements leaving the screen
cubic-bezier(0.4, 0, 1, 1)
ease-in-out
Elements staying on screen (default)
cubic-bezier(0.4, 0, 0.2, 1)

Animation Patterns

STREAMING TEXT
Fade-in with subtle translateY
opacity: 0 → 1; transform: translateY(4px) → 0
Duration: 300ms, ease-out
SKELETON LOADING
Subtle pulse animation
opacity: 0.3 ↔ 0.15
Duration: 1.5s, ease-in-out, infinite
MODAL ENTRANCE
Scale + fade backdrop
scale: 0.95 → 1; opacity: 0 → 1
Duration: 200ms, ease-out
TOAST NOTIFICATIONS
Slide from edge
translateX: 100% → 0
Duration: 300ms, ease-out

PRINCIPLES

  • Animations should feel instant (< 300ms for most interactions)
  • Always respect prefers-reduced-motion
  • Avoid animating layout properties (use transform/opacity)
  • Never animate during text streaming (causes jank)
  • Use animation to provide feedback, not decoration
