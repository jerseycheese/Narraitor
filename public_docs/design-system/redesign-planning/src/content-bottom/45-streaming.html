IMPLEMENTATION NOTES

  • Text is tokenized by whitespace: text.split(/(\s+)/)
  • Each word wrapped in <span class="manuscript-streaming-word"> with fade-in animation
  • Whitespace preserved as plain text nodes (no animation)
  • Container auto-scrolls to follow new content
  • No layout shift - words appear inline within existing paragraph flow
