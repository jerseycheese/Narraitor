Content & Voice

Writing guidelines for UI text, labels, and microcopy.

Voice & Tone

NARRATIVE VOICE
Immersive, Evocative, Story-Driven

The AI-generated narrative sets the genre and tone. Our UI should not compete with it—it provides a neutral, elegant frame.
SYSTEM VOICE
Precise, Technical, Unobtrusive

System messages use monospace typography and technical language—think drafting annotations rather than conversational UI.

Writing Patterns

BUTTON LABELS
✓ Do
  • "Continue to Attributes"
  • "Save Character"
  • "Start New Game"
✗ Don't
  • "Click here to continue"
  • "Save"
  • "OK"
SYSTEM LABELS
✓ Do
  • "HEALTH: 42/50"
  • "TURN 14"
  • "LAST_SAVE: 2m ago"
✗ Don't
  • "Your health is 42 out of 50"
  • "Turn fourteen"
  • "Saved 2 minutes ago"
ERROR MESSAGES
✓ Do
  • "Character name required"
  • "Connection lost. Reconnecting..."
  • "Could not load world. Try again."
✗ Don't
  • "Oops! Something went wrong"
  • "Error code: CHAR_NAME_NULL"
  • "Please enter a name"

GUIDELINES

  • Use sentence case for all UI text (not Title Case)
  • System labels use ALL_CAPS with underscores for technical feel
  • Be direct—avoid "please" and unnecessary politeness
  • Use active voice ("Save character" not "Character will be saved")
  • Front-load important information in longer messages
