Responsive Design

Mobile-first approach with graceful scaling across all devices.

Breakpoint Strategy

BASE (Mobile First)
0px - 639px
DEFAULT
Single column layouts, stacked navigation, full-width components. Touch-optimized with 44px minimum tap targets.
sm
640px+
LARGE PHONES
Slightly wider content, may introduce 2-column layouts for cards. Navigation remains mobile-optimized.
md
768px+
TABLETS
Transition point: sidebar navigation appears, 2-3 column grids, narrative text stays at optimal reading width.
lg
1024px+
LAPTOPS
Full desktop layout: HUD panels appear, Workshop sidebar visible, multi-column data tables.
xl / 2xl
1280px+ / 1536px+
LARGE DISPLAYS
Max content width maintained (1280px), increased margins. Narrative column stays at optimal 768px.

Layout Adaptation Patterns

THE MANUSCRIPT (MOBILE)
HUD (Collapsible)
NARRATIVE (Full Width)
INPUT (Fixed Bottom)
  • HUD collapses to expandable drawer
  • Narrative uses full width (16px padding)
  • Suggested actions stack vertically
  • Input remains fixed at bottom
THE WORKSHOP (MOBILE)
TOP NAV + PROGRESS
WORKSPACE (Full Width)
ACTION BUTTONS
  • Sidebar becomes top navigation tabs
  • Progress bar moves to top
  • Forms stack into single column
  • Action buttons fixed at bottom or sticky

Touch Optimization

MINIMUM SIZES
  • Tap targets: 44px × 44px
  • Button height: 48px
  • Input height: 48px
  • List items: 56px
  • Icon buttons: 44px
SPACING
  • Between targets: 8px min
  • Edge padding: 16px
  • Section gaps: 24px
  • Safe area insets: Respected
  • Thumb zones: Considered

Typography Scaling

FLUID TYPE SCALE

Body text (mobile) 14px → 16px (tablet+)
h1 (mobile) 28px → 36px (desktop)

Mobile-Specific Patterns

NAVIGATION
  • Bottom tab bars preferred
  • Hamburger menu for overflow
  • Swipe gestures for navigation
  • Back button in top-left
  • Breadcrumbs hidden on mobile
INTERACTIONS
  • Pull-to-refresh support
  • Long-press for context menus
  • Swipe actions on list items
  • Modal sheets vs. full modals
  • Toast notifications at top
FORMS
  • One input per row
  • Large touch targets
  • Native keyboard types
  • Inline validation
  • Fixed submit buttons
CARDS & LISTS
  • Horizontal scroll for cards
  • Infinite scroll for lists
  • Skeleton loaders
  • Optimistic UI updates
  • Swipe for actions

IMPLEMENTATION

  • Use Tailwind responsive prefixes: md:flex, lg:grid-cols-3
  • Test on real devices, not just browser DevTools
  • Consider touch vs. mouse hover states
  • Use env(safe-area-inset-*) for notched devices
  • Lazy load below-the-fold content on mobile
  • Optimize images with responsive srcset
