Elevation & Shadows

Minimal shadow system for creating depth hierarchy. Use sparingly to maintain the "drafting table" aesthetic.

shadow-sm
0 1px 2px rgba(0,0,0,0.05)
Subtle depth for cards
shadow-md
0 4px 6px rgba(0,0,0,0.1)
Dropdowns, tooltips
shadow-lg
0 10px 15px rgba(0,0,0,0.1)
Modals, floating panels

USAGE NOTE

Prefer backdrop-blur and borders over shadows for the HUD panels to maintain the "technical blueprint" aesthetic. Use shadows only for floating elements that need clear separation.
